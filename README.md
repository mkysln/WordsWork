# WordsWork

WordsWork, kelime öğrenme ve tekrar sürecini mobil cihazda düzenlemeyi amaçlayan bir uygulamadır. Kelimeleri seviyelere göre çalışmayı, yeni kelimeler eklemeyi ve artık aktif çalışılmayan kelimeleri arşivden gözden geçirmeyi sağlar.

Kelime kayıtları cihazda yerel olarak tutulur; uygulama React Native ile geliştirilmiştir.
